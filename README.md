# تقنية التحكم المبرمج (عملي) — الكتاب التفاعلي

الكتاب التفاعلي لمقرر **205 كهر — تقنية التحكم المبرمج (عملي)**: 10 وحدات و45 درساً. كل درس فيه شرح مطابق للكتاب مع أرقام صفحاته وأشكاله، ومحاكاة حية للدائرة والبرنامج (LAD / FBD / STL) والجهاز.

- يعمل مباشرة من المتصفح على الجوال والكمبيوتر، ويمكن إضافته للشاشة الرئيسية ويعمل بدون إنترنت بعد أول فتح.
- أرقام التيار والسرعة في المحاكاة توضيحية.

المصدر: مذكرة مقرر تقنية التحكم المبرمج (عملي) 205 كهر.
