# المكتبة الرقمية لقسم التقنية الكهربائية

كتب مقررات قسم التقنية الكهربائية (كلية السليل التقنية) بشكل تفاعلي: شرح مطابق للمذكرات بأرقام صفحاتها وأشكالها، ومحاكاة حية لكل درس، واختبارات.

- `index.html` — واجهة المكتبة، وقائمة المقررات في `library.js`.
- `courses/<المقرر>/` — كتاب كل مقرر (الوحدات في `course.js` والدروس في `lessons/`).
- `shared/` — المحرك المشترك والتصميم والخطوط.

يعمل على الجوال والكمبيوتر، ويمكن إضافته للشاشة الرئيسية ويعمل بدون إنترنت بعد أول فتح.
